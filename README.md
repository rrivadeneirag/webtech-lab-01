This repository contains the source code (HTML, CSS and JavaScript) of my
personal page for Web Technologies Labs 1 and 2.

## Lab 2 — Interactive features

- **Movie catalog (built from data):** the "My Movies" section is generated
  from a JavaScript array of movies when the page loads.
- **Filter by title:** in "My Movies", type in the "Search by title" box and
  the list narrows as you type; clear the box to bring every movie back.
- **Filter by genre:** in "My Movies", choose a genre from the "Filter by
  genre" dropdown to show only that genre; choose "All genres" to reset.
- **Add a movie:** in "My Movies", fill the "Add a movie" form (title, year,
  genre) and click "Add movie" to add a new card to the catalog.
- **Remove a movie:** in "My Movies", click the "Remove" button on any card to
  delete it (this also works on movies you just added).
- **Contact form validation:** in the "Contact" section, click "Send" with
  empty or invalid fields to see an error message next to each field; a valid
  submission shows a confirmation message.
- **Dark mode toggle:** in the header at the top of the page, click the
  "Dark mode" button to switch the page between light and dark themes.
